# Art and sound provenance

`hero.png` and `apostle.png` are copied without byte changes from the existing Eclipse Survival prototype. Each is a 1024×1536 transparent RGBA PNG. The hero was generated by editing the supplied simplified-protagonist reference: white background and badge removed, design kept close. It is **not pixel-identical** to the reference; face/clothing pixels changed slightly. The Apostle is an original generated horned creature. Both have faint low-alpha halos outside the main figure.

Unity import metadata selects these source rectangles (bottom-left image coordinates):

| Sprite | X | Y | Width | Height | Pivot |
|---|---:|---:|---:|---:|---|
| Hero | 192 | 172 | 656 | 1230 | bottom center |
| Apostle | 247 | 9 | 625 | 1521 | bottom center |

Original file pixels remain unchanged. Import uses point filtering, no mipmaps, no texture compression, and a full rectangle mesh. The atlas includes hero, Apostle, and two original procedural human sprites. The current art is a mixture of supplied-reference character art and simple original generated tiles/props; it is not a finished cohesive production tileset.

The directional Animator controller has North/South/East/West states but deliberately shares the one supplied hero pose. It supplies editable animation slots, not new directional artwork. Horizontal facing uses sprite mirroring. Movement, crouch and crawl have simulation behavior; their presentation remains placeholder scaling/facing, with combat drawn through pooled line effects. Replace the clips with authored frames for finished locomotion.

`PixelArt.Texture` creates original small grass/road/floor tiles, houses, trees, cars, crates, shadows, bandit and scavenger placeholders. Asset setup writes these to Resources/Generated so runtime can reuse imported sprites. The Art/Tilesets, Art/Props and Art/UI folders are reserved for authored replacements.

Audio placeholders are original deterministic synthesis in ProjectSetup: wind, bird chirps, heartbeat, distortion, melee and hurt. They are generated as mono WAV and imported through Unity's AudioImporter. There are no ripped game sprites, music, or commercial sample dependencies. Unity template project settings are derived from the editor's 2D URP starter template; Unity runtime/package licensing still applies normally.
